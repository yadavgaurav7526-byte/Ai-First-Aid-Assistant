# Ai-First-Aid-Assistant

An AI-powered first-aid assistant that helps people access basic first-aid information and guidance during emergencies.

## About
I built this project to make first-aid information easier to access. It uses Google's Gemini API to answer first-aid-related questions and analyse uploaded images. It also includes predefined guides for common emergencies and supports multiple languages.

## Features
- AI-powered first-aid guidance.
- Image upload and AI-based injury analysis.
- Supports English, Hindi, Marathi, Bengali, Tamil and Kannada.
- First-aid guides for burns, bleeding, fractures, choking, snake bites and CPR.
- Location support.
- PDF report generation.

## Tech Stack
Python, Streamlit, Google Gemini API.

## Deployment
The application is being prepared for deployment. The Gemini API key is configured through environment variables to keep it secure.

## Disclaimer
This project is made for educational purposes and provides basic first-aid information. AI responses and image analysis may not always be accurate. Always seek professional medical help during emergencies.
